# Notebooks

All notebooks should be run from the **project root** (the directory containing the top-level `README.md`), either via `jupyter lab` or `jupyter notebook`.

| # | Notebook | Phase | Description |
|---|----------|-------|-------------|
| 01 | [`01_sand_brightness_analysis.ipynb`](01_sand_brightness_analysis.ipynb) | Evaluation | Sand reflectance and colorimetric analysis to contextualise model performance differences between sites. Requires `results/metrics/beach_brightness_*` files generated by `src/04_evaluation/calc_beach_brightness.py`. |
| 02 | [`02_pixel_metrics_evaluation.ipynb`](02_pixel_metrics_evaluation.ipynb) | Evaluation | IoU and Dice scores for the spectral-index baselines at pixel level. |
| 03a | [`03a_pixel_metrics_dl_binary.ipynb`](03a_pixel_metrics_dl_binary.ipynb) | Evaluation | IoU and Dice scores for DL models under a binary (water / no-water) formulation. |
| 03b | [`03b_pixel_metrics_dl_multiclass.ipynb`](03b_pixel_metrics_dl_multiclass.ipynb) | Evaluation | Per-class pixel metrics for the multiclass DL segmentation outputs. |
| 04 | [`04_cross_shore_offsets_analysis.ipynb`](04_cross_shore_offsets_analysis.ipynb) | Evaluation | Geometric benchmarking: cross-shore offset analysis along shore-normal transects for all models. Produces the main comparative figures in the thesis. |
| — | [`check_exported_sdw.ipynb`](check_exported_sdw.ipynb) | QC | Quick visual inspection to compare exported SDW lines against reference waterlines before running the offset analysis. |

## Shared utilities

Common evaluation functions (IoU, Dice, boundary zone mask, metric aggregation) live in [`src/utils/evaluation_utils.py`](../src/utils/evaluation_utils.py). The `utils/` folder in this directory keeps a working copy for backward compatibility; the canonical source is `src/utils/`.
