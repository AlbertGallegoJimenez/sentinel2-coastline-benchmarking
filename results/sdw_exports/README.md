# results/sdw_exports

Shoreline Detection Waterlines (SDW) extracted by all methods.

## Subdirectories

### `raw/`
Raw SDW shapefiles as produced directly by the extraction algorithms:
- Index-based SDW: generated by `src/02_baselines/02_extract_baseline_sdw.py`
- DL-based SDW: generated by `src/03_deep_learning/03_extract_dl_sdw.py`

These files **have not been spatially filtered** and may contain spurious segments (e.g. inland water bodies, boundary artefacts).

### `filtered/`
SDW shapefiles after **manual spatial filtering in QGIS** using the reference polygons in `data/gis_reference/`. These are the files used in the final evaluation notebooks.

Naming convention: `sdw_{site}_{method}.shp` (e.g. `sdw_puntal_mndwi_otsu.shp`, `sdw_salinas_unet_mit_b4.shp`).
